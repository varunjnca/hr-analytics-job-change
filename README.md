# HR Analytics: Job Change Prediction

Exploratory analysis and machine-learning work on factors associated with job changes among data science candidates.

## Contents

- `hr-analytics-job-change.ipynb` - Jupyter notebook with the analysis.

## Getting started

Open the notebook in Jupyter Notebook, JupyterLab, or Google Colab and run the cells in order. The notebook expects the training and test CSV files to be available at the paths specified in its data-loading cells.

## Data

The notebook uses the HR Analytics job-change dataset. See the notebook for the exact features, preprocessing, and modeling workflow.
